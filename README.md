# 🤖 Basic Chatbot Using Python

## 📌 Project Overview

The **Basic Chatbot** is a simple Python-based application that interacts with users through text conversations. It responds to basic messages and predefined questions using conditional statements and keyword matching.

This project was developed as part of my **Python Programming Internship at CodeAlpha** to gain practical experience in Python programming and chatbot development.

## 🎯 Objectives

* Build a simple chatbot using Python.
* Understand user input and automated responses.
* Practice conditional statements and loops.
* Improve logical thinking and problem-solving skills.
* Learn the fundamentals of conversational applications.

## ✨ Features

* 💬 Interactive text-based conversation.
* 👋 Responds to greetings such as hello and hi.
* 😊 Provides predefined responses to common questions.
* 🕒 Displays basic date or time information if implemented.
* 👋 Supports a goodbye message to end the conversation.
* ⚡ Lightweight and easy to run.
* 🐍 Built using basic Python concepts.

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Concepts:** Variables, strings, loops, conditional statements, and user input/output.
* **Development Environment:** Visual Studio Code (VS Code)

## 🚀 How to Run the Project

### Step 1: Clone the Repository

Open your terminal and run:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### Step 2: Open the Project Folder

```bash
cd Basic-Chatbot
```

### Step 3: Run the Python Program

```bash
python chatbot.py
```

If the `python` command does not work on Windows, try:

```bash
py chatbot.py
```

### Step 4: Start Chatting

Enter a message in the terminal and interact with the chatbot.

For example:

```text
Chatbot: Hello! Welcome to the Basic Chatbot.
You: Hi
Chatbot: Hello! How can I help you?

You: How are you?
Chatbot: I'm doing well! Thanks for asking.

You: Bye
Chatbot: Goodbye! Have a great day!
```

*Note: The sample conversation illustrates expected behavior; actual responses depend on the implementation in `chatbot.py`.*
